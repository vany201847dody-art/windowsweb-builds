# Сборки ОС от ИИ — архив исходников

Здесь лежат все варианты «Windows 11 в браузере», созданные разными ИИ. Код можно свободно копировать и переиспользовать: каждая сборка — один самодостаточный HTML-файл (без внешних скриптов).

## Сборки

| Файл | Статус | Система |
|------|--------|---------|
| `vssesuperbild.html` | ✅ итоговая | **Windows 11** — финальная рабочая сборка, лежит на сайте в `windowsweb`. |
| `grok.html` | 🟢 от Grok | **AetherOS** — 24 приложения, Диспетчер задач, Погода, Paint, Камера, Браузер, ресайз окон по всем точкам. |
| `novaos.html` | ✅ сборка | **NovaOS v1.0** — собственная минифицированная сборка Vizor (© Vizor 2026). |
| `novashell.html` | 🟡 шелл | **NovaShell — Vizor** — свой концепт-шелл (© Vizor). |
| `DEEPSEEK.html` | 🟡 рабочий | **NovaOS 1.0** — отсюда взяты Банк, QR-код, Диктофон, Заметки, Игры, Мировые часы. |
| `deepseek.html` | 🟠 ранняя | **GoodWin 11** — более старая версия этой же сборки. |

| `gigschat.html` | 🔴 неудачная | **NovaOS** — эксперимент, базовые окна без оболочки. |

`prompt.txt` — общее задание (ТЗ), по которому генерировались сборки.

`grok-workspace.zip` — исходник новой версии от Grok: Vite + TanStack (src/os с 17 приложениями на TSX), авторизация grok-identity, деплой на Vercel.

## Галерея

Сайт-галерея (индексная страница) — это `index.html` + внешние `styles.css` и `gallery.js`.
Просмотр закрыт строгим CSP, сборки грузятся в sandbox-iframe (неудачные — без доступа к странице).

## Как скопировать

1. Откройте нужный `.html` (кнопка «Raw» в углу или обычный просмотр кода).
2. Сохраните страницу/выделите весь код → вставьте в файл `index.html`.
3. Откройте файл двойным кликом — ОС запустится в браузере.

Каждая сборка открывается и как сайт:

- https://github.com/vany201847dody-art/windowsweb-builds/blob/main/`<файл>`
