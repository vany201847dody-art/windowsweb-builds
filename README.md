# Сборки ОС от ИИ — архив исходников

Здесь лежат все варианты «Windows 11 в браузере», созданные разными ИИ. Код можно свободно копировать и переиспользовать: каждая сборка — один самодостаточный HTML-файл (без внешних скриптов).

## Сборки

| Файл | Статус | Описание |
|------|--------|----------|
| `vssesuperbild.html` | ✅ итоговая | Финальная рабочая сборка, лежит на сайте в `windowsweb`. |
| `DEEPSEEK.html` | 🟡 рабочий | Отсюда взяты Банк, QR-код, Диктофон, Заметки, Игры, Мировые часы. |
| `deepseek.html` | 🟠 ранняя | Более старая версия этой же сборки. |
| `алиса аи.html` | 🔴 неудачная | Ранний вариант, функциональность сильно ограничена. |
| `gigschat.html` | 🔴 неудачная | Эксперимент, базовые окна без оболочки. |

`prompt.txt` — общее задание (ТЗ), по которому генерировались сборки.

## Галерея и комментарии

Сам сайт-галерея (индексная страница) — это `index.html` + внешние `styles.css` и `gallery.js`.
Просмотр закрыт строгим CSP, сборки грузятся в sandbox-iframe. Комментарии проходят антимат-фильтр, выводятся как текст (HTML не исполняется) и подписываются именем/ссылкой на профиль автора.
Владелец может удалить любой комментарий (кнопка ✕, пароль задаётся при первом удалении). Постоянные комментарии — через GitHub Issues (кнопка на карточке).

## Как скопировать

1. Откройте нужный `.html` (кнопка «Raw» в углу или обычный просмотр кода).
2. Сохраните страницу/выделите весь код → вставьте в файл `index.html`.
3. Откройте файл двойным кликом — ОС запустится в браузере.

Каждая сборка открывается и как сайт:

- https://github.com/vany201847dody-art/windowsweb-builds/blob/main/`<файл>`
